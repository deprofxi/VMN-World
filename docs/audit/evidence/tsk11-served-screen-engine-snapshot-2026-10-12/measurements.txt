== Why those two stay unsupplied (verified by reading the sources) ==
  playoutStatus : src/modules/broadcast/playout/index.ts:71 PlayoutAutomationEngine composes playlists;
                  it holds no on-air flag and no playlist-lock flag, and there is no machine adapter in src/.
                  Serving `{onAir, lockedPlaylist}` would be an invented operational state on the live monitor.
  asRunSummary  : the durable shape exists — prisma `model AsRunLogRecord` (prisma/schema.prisma:409) with exactly
                  totalPlannedSpots / totalAiredSpots / matchedSpots / discrepancyCount, written by
                  ScheduleRepository.recordAsRun (src/core/database/repositories/schedule.repository.ts:328) and read by
                  listAsRunRecords (:395). NEITHER has a caller in src/:
                    `grep -rn "recordAsRun\|listAsRunRecords" src | grep -v schedule.repository.ts` -> 0 hits
                    the only test that writes and reads the pair is tests/unit/production-core-and-infrastructure.test.ts:200,:212.
                  The rows that DO exist were inserted by the demo seed (src/db/migrate-and-seed.ts:189 upsert).
                  So the process can read seeded fixtures but has no ingestion path: reconciliation itself is
                  request-scoped (reconcileAsRunLogs, src/modules/broadcast/asrun/index.ts:345) and the engine is
                  stateless (:405). Presenting seeded rows as "as-run ingested for the selected date" is the exact
                  invention TSK-11 deleted from this panel ("264 Total Spots Ingested"), so the panel stays
                  NOT_CONNECTED until a route ingests operator-posted logs into that table.
