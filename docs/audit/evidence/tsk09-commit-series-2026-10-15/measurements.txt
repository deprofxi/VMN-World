## 1. Self-containment, per revision

```bash
node self-containment-probe.mjs 61355c6   # before the series (script archived beside this file)
node self-containment-probe.mjs 85aad76   # tip of the code series
```

The probe lists a revision's own tracked files with `git ls-tree -r <rev>
--name-only`, reads each one's contents with `git show <rev>:<path>`, resolves
every relative `from "./…"` import against that same list, and reports the
imports that resolve to nothing in that revision. `head-self-containment.txt`
carries both outputs verbatim.

```
61355c6 → 10 absent imports          85aad76 → 0
```

Working-tree variant (same resolution rule, contents read from disk): 15 absent
modules at the moment the series started, which is why the closure says "ten in
the repository, fifteen as the tree stood".
