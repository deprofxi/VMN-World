2. CURRENT CLAUDE-SPECIFIC DESIGN BASIS

Anthropic’s current prompting guidance recommends explicit, direct instructions; structured prompts using descriptive XML tags for complex tasks; explicit tool-use instructions where action is expected; and careful use of subagents, especially because modern Claude models can delegate aggressively when simpler direct work may be more appropriate. 

Accordingly, this pack standardises prompts around explicit sections such as:

<authority>
<objective>
<context>
<scope>
<constraints>
<execution>
<tests>
<evidence>
<stop_conditions>
<handoff>

The pack also avoids locking engineering policy to a specific Claude model name. Anthropic actively changes its model portfolio and deprecates older versions over time, so the model selection itself should remain configuration/runtime policy rather than enterprise architecture.
